# 에셋 교체 안내

지금 들어 있는 그림/소리는 전부 `tools/make_placeholders.py` 가 만든 **임시(플레이스홀더)** 입니다.
진짜 에셋으로 바꿀 때는 **같은 이름, 같은 크기, 같은 칸 배치**로 덮어쓰기만 하면 됩니다. 코드는 고칠 필요 없음.

- 칸마다 번호와 이름이 붙은 안내 그림: `docs/asset_guide_*.png` (그림을 바꾼 뒤 `python3 tools/make_asset_guide.py` 로 다시 그릴 수 있음)
- 한 칸 = **16x16 픽셀**, 게임 화면 = **320x180** (정수배로 확대됨). 투명 배경 PNG.
- ⚠ 교체한 뒤에는 `python3 tools/make_placeholders.py` 를 **다시 돌리지 마세요.** 임시 그림으로 다시 덮어씁니다.
- Godot 편집기를 켜 두면 파일을 바꿀 때 자동으로 다시 불러옵니다(`.import` 파일은 그대로 두면 됨).

## 소리 (`assets/audio/`)

같은 이름의 `.ogg` 나 `.mp3` 를 넣으면 `.wav` 보다 **먼저** 씁니다. (예: `bgm_home.ogg` 를 넣으면 그걸 씀. 용량도 훨씬 작아짐)
배경음은 끝나면 처음부터 다시 틀어 주니 따로 반복 설정은 안 해도 됩니다.

| 파일 | 언제 나오나 |
|---|---|
| `bgm_home` | 집, 타이틀(조금 낮게), ???의 집(더 낮게 0.8배) |
| `bgm_town` | 마을 |
| `bgm_shop` | tHE shop |
| `bgm_field` | 운동장(2일차), 마당(4일차, 조금 낮게) |
| `sfx_blip` | 대사 글자 찍힐 때, 선택지 위아래 |
| `sfx_select` | 선택지 고를 때 |
| `sfx_quest` | 퀘스트 받기/완료, 물건 줍기, 잡초 뽑기 |
| `sfx_coin` | 골드 받기, 물건 사기 |
| `sfx_door` | 문 지나갈 때, 3일차 창고 문 "철컥" |
| `sfx_whisper` | 환청 (밤마다 나는 소리도 이것. 4일차 밤엔 일부러 안 남) |
| `sfx_glitch` | 지직거림, 글씨 일그러짐, 로딩 멈칫 |
| `sfx_rush` | 2일차 "무언가"가 달려올 때 |

## 글꼴 (`assets/fonts/`)
`Galmuri9.ttf`, `Galmuri11.ttf` 는 임시가 아니라 진짜 픽셀 한글 글꼴입니다(SIL OFL 라이선스, `Galmuri-LICENSE.txt`).
바꾸고 싶으면 같은 이름으로 덮어쓰면 되는데, **한글과 ㄱ~ㅎ 낱자, ■□▲▼◀▶** 가 들어 있는 글꼴이어야 글자가 안 깨집니다.

## 새로 만들 수 있는 것 (지금 없음)
- 캐릭터를 16x16보다 크게(예: 16x32) 그리고 싶으면 코드에서 위치를 올려 줘야 합니다. 말해 주면 맞춰 드림.
- 타이틀 화면 배경 그림은 지금 없습니다(단색). 원하면 `title.png` 자리 만들어 드림.
