# 휴대폰에서 테스트하기

휴대폰(터치 화면)에서 켜면 화면에 **터치 버튼**이 자동으로 나옵니다.
- 왼쪽: ▲▼◀▶ 이동, `달리기`(누를 때마다 켜기/끄기)
- 오른쪽: `A` 확인/말 걸기, `B` 취소, `지도`
- 대사가 나올 때는 버튼이 숨고, **화면 아무 데나 누르면** 다음 대사로 넘어갑니다.

PC에서 터치 버튼 모양만 미리 보려면: `godot --path . -- --touch`

내보내기 설정(`export_presets.cfg`)에 **Web**, **Android** 두 가지가 이미 들어 있습니다.
처음 한 번은 Godot 편집기에서 **편집기 → 내보내기 템플릿 관리 → 다운로드 및 설치** (4.3 버전용) 를 해 주세요.

---

## 방법 1. 웹으로 (안드로이드 + 아이폰 둘 다, 제일 쉬움)

1. Godot 편집기 → **프로젝트 → 내보내기 → Web → 프로젝트 내보내기** → `export/web/index.html`
2. `export/web` 폴더 안의 파일들을 **HTTPS 주소**에 올립니다.
   - ⚠ 웹 버전은 **HTTPS(또는 그 컴퓨터의 localhost)** 에서만 켜집니다.
     같은 와이파이에서 `http://컴퓨터IP:포트` 로 열면 "Secure Context" 오류가 나요.
   - **itch.io (추천)**: `export/web` 안 파일들을 zip 으로 묶어서 새 프로젝트에 올리고,
     Kind of project = **HTML**, "This file will be played in the browser" 체크.
     공개 설정을 **Draft(초안)** 로 두면 나만 볼 수 있음. 화면 크기는 1280x720 정도.
   - GitHub Pages, Netlify(폴더 끌어다 놓기) 같은 무료 HTTPS 호스팅도 됩니다.
3. 휴대폰 브라우저(크롬/사파리)로 그 주소를 열고, **가로 화면**으로 돌리면 됩니다.
   - 소리는 화면을 한 번 누른 뒤부터 나옵니다(브라우저 규칙).

## 방법 2. 안드로이드 앱(APK)으로

처음 준비 (한 번만):
1. **JDK 17** 설치 (예: Adoptium Temurin 17)
2. **Android SDK** 설치 (Android Studio 를 깔면 같이 깔림. 또는 command-line tools 로
   `platform-tools`, `build-tools;34.0.0`, `platforms;android-34`)
3. Godot → **편집기 → 편집기 설정 → 내보내기 → Android** 에서
   `Java SDK 경로`, `Android SDK 경로` 지정.
   (디버그용 서명 키는 보통 Godot이 알아서 만들어 줍니다. 오류가 나면 그 메시지를 알려 주세요.)

휴대폰 쪽:
4. **설정 → 휴대전화 정보 → 소프트웨어 정보 → 빌드번호**를 7번 눌러 개발자 모드 켜기
5. **설정 → 개발자 옵션 → USB 디버깅** 켜기, USB 로 PC 와 연결 (휴대폰에 뜨는 "허용" 누르기)

실행:
6. Godot 오른쪽 위에 생기는 **안드로이드 아이콘(원클릭 배포)** 을 누르면 휴대폰에 설치되고 바로 켜집니다.
   - 또는 **프로젝트 → 내보내기 → Android → 프로젝트 내보내기** 로 `your_quest.apk` 를 만들어서
     휴대폰에 옮긴 뒤 설치 ("출처를 알 수 없는 앱 설치" 허용 필요).

## 아이폰 앱으로?
아이폰 앱으로 직접 설치하려면 **Mac + Xcode + 애플 개발자 계정**이 필요합니다.
그냥 테스트용이라면 **방법 1(웹)** 을 쓰세요.
